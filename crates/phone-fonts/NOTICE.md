# Selawik font attribution

The unmodified Regular, Light, Semibold and Bold font files are from
[Microsoft Selawik release 1.01](https://github.com/microsoft/Selawik/releases/tag/1.01).
They are distributed under the SIL Open Font License 1.1 included in `LICENSE.txt`.

Downloaded release archive: `Selawik_Release.zip`.
SHA-256: `3f62c51e05e3b5a1e6241cf92a371f0be2ea1183aa87b30718bbd40832a8d423`.
Source repository revision inspected: `89362e84731d1f5777fa078fd4d5ebbd339e4378`.

Microsoft describes Selawik as an open replacement for Segoe UI. It is not Segoe
WP, and the upstream project records differences in kerning and hinting. This
collection improves the portable Metro typography without asserting identical
original-device text rasterization. Licensed Segoe WP or Segoe UI installed on a
native host remains ahead of Selawik in the phone theme's fallback list.
